# Archive

How Gathr was built up to 2026-11-19. On 2026-11-20 the owner decided to start the chat and the team layer over, and to
put away the rules and paperwork that led to an app with more guards, messages and tests than work.

**Nothing here is a rule, and nobody keeps it up to date.** Links inside these files may be dead: they were written for
where the files used to be. The rules are in [AGENTS.md](../../AGENTS.md).

| File | What it was |
|---|---|
| `AGENTS-2026-11-19.md` | The rulebook as it stood: plans before code, a test first, a review and a hear-back for every change, friction as requirements, the owner's room |
| `charter.md` | What Gathr was for, the loop work followed and its eleven promises |
| `truth-map.md` | Each promise, part by part, with the code and the test that proved it |
| `scenarios.md` | Each promise as given, when, then |
| `testing.md` | How tests were written, test first |
| `first-slice.md` | The first slice built |
| `decisions/` | Every numbered decision, 0001 to 0086. Code comments cite them by number |

They are kept because the code's comments point at the decisions, and because the parts under the chat (engines,
logins, storage, updates) are still as their decisions describe.
