# Agent editing

All three options use the same engine, account, searchable model list and effort
fields. The composer selects an agent; it never overrides that agent's model.

1. Settings > Agents, v1.html (selected). A stable home for reusable agents,
   with five agents beside the form. Works the same from a single or team chat.
2. Team panel, v2.html (not chosen). Edit beside the conversation. Less space for long model
   lists, and shared agent changes can look like chat-specific changes.
3. Chat agent menu, v3.html (not chosen). A compact editor beside the recipient control.
   Quick access, but less discoverable as the home for reusable agents.

Edit agent in the selected page's chat picker opens Settings at that agent.
Save changes the agent everywhere it is used, from the next turn. Running turns
keep their assignment. There is no Scope control. Roles remain specific to each chat.
All fixture names, accounts, models and efforts are samples. Choices are not a
claim about currently supported provider capabilities. Production discovery waits
for the engine research. No network, credentials, clipboard or durable storage.

Open each page; append #light or use Switch theme. Choose an agent, change its
engine and account, find model 24, select it, choose effort and Save. Open Settings
to inspect the saved values. Choose Rowan in the chat picker, then Edit agent:
Settings opens at Rowan. Change the engine to check resets.
Cancel or Escape discards edits. Reload clears every preview change.
